# Student Management System (Python)

A simple console-based Student Management System built using Python.  
This project allows users to manage student records, including adding students, assigning grades, calculating GPA, and sorting students based on performance.

---

## 🚀 Features

- Add new students (ID and name)
- Add grades for students
- Display all students
- Search for a specific student
- Delete student records
- Calculate GPA automatically
- Sort students by GPA (highest to lowest)
- Save data to file (JSON)
- Load data automatically on startup

---

## 🛠️ Technologies Used

- Python 3
- File handling (JSON)
- Lists and dictionaries
- Sorting algorithms (built-in sorted function)
